## 🛠️ เครื่องมือและเทคโนโลยีที่ใช้ (Tech Stack)

### Frontend
- **Framework & Build Tool**: React 19 + Vite 8
- **Routing**: React Router v8 (BrowserRouter พร้อมไฟล์ `frontend/vercel.json` สำหรับ URL Rewrite)
- **Styling & UI Components**: TailwindCSS v4 + DaisyUI v5 (ธีมสว่าง สะอาดตา) + Lucide React
- **Notifications & Dialogs**: SweetAlert2 (ยืนยันการลบพร้อมระบุชื่อหนังสือ และแจ้งเตือนผลลัพธ์)

### Backend
- **Runtime & Server**: Node.js + Express v5 (ES Module)
- **ORM & Database**: Sequelize v6 เชื่อมต่อฐานข้อมูลเชิงสัมพันธ์ PostgreSQL (`pg`, `pg-hstore`)
- **Utility & Middleware**: `cors` (รองรับ Origin จาก Vercel และ Localhost), `dotenv`
- **Development Tool**: `nodemon`

## 📋 โครงสร้างข้อมูลและเงื่อนไข (Data Specification)

**ตารางหลัก (Table Name)**: `books` | **Sequelize Model**: `Book` | **Resource / API Endpoint**: `/api/books`

| ฟิลด์ (Field) | ชนิดข้อมูล (Data Type) | ข้อกำหนดและความถูกต้อง (Validation Constraints) | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `id` | `INTEGER` | Primary Key, Auto Increment | รหัสหนังสือ (จำนวนเต็มบวก) |
| `title` | `STRING(150)` | `allowNull: false`, ความยาว 1–150 ตัวอักษร, ห้ามว่างล้วน | ชื่อหนังสือ |
| `author` | `STRING(100)` | `allowNull: false`, ความยาว 1–100 ตัวอักษร, ห้ามว่างล้วน | ผู้แต่ง (ผู้รับผิดชอบตามชุด) |
| `category` | `STRING(50)` | `allowNull: false`, ต้องเลือกจาก 3 หมวดหมู่ที่กำหนดเท่านั้น | หมวดหมู่หนังสือ |
| `publishedDate` | `DATEONLY` | `allowNull: false`, วันที่ถูกต้องตามปฏิทิน รูปแบบ `YYYY-MM-DD` | วันที่เผยแพร่ (วันที่ตามชุด) |
| `description` | `TEXT` | `allowNull: false`, ความยาว 1–2,000 ตัวอักษร, ห้ามว่างล้วน | รายละเอียดหนังสือ |
| `status` | `BOOLEAN` | `allowNull: false`, ค่าเริ่มต้น `true` | สถานะ (`true` = เผยแพร่, `false` = ฉบับร่าง) |
| `createdAt` / `updatedAt` | `TIMESTAMP` | Auto-generated by Sequelize | วันเวลาที่สร้างและปรับปรุงข้อมูล |

## 🗄️ การสร้างฐานข้อมูล (Database Setup)

รองรับทั้ง Local PostgreSQL, Docker Compose และ Cloud PostgreSQL (เช่น Neon, Render, Supabase):

### กรณีที่ 1: ใช้ Docker Compose (สะดวกที่สุดในเครื่อง)
```bash
docker compose up -d postgres-db
```

### กรณีที่ 2: ใช้ Cloud Database (เช่น Neon.tech)
สร้างโปรเจกต์บน Neon แล้วคัดลอก Connection String เช่น:
```text
postgresql://user:password@ep-xyz.us-east-1.aws.neon.tech/neondb?sslmode=require
```

## 📡 ข้อกำหนด RESTful API

| Method | Endpoint | หน้าที่ | Response สำเร็จ | Response เมื่อมีข้อผิดพลาด |
| :---: | :--- | :--- | :---: | :--- |
| `GET` | `/api/books` | อ่านรายการ, ค้นหา (`?q=...`), กรอง (`?category=...`) | `200 OK` + Array ข้อมูล (ไม่พบ -> `200` + `[]`) | `500` ข้อผิดพลาดระบบ |
| `GET` | `/api/books/:id` | อ่านรายละเอียดหนึ่งรายการ | `200 OK` + Object | `400` ID ไม่ใช่จำนวนเต็มบวก / `404` ไม่พบ |
| `POST` | `/api/books` | เพิ่มรายการหนังสือใหม่ | `201 Created` + Object | `400` ข้อมูลไม่ครบหรือไม่ผ่านเงื่อนไข |
| `PUT` | `/api/books/:id` | แก้ไขทุกฟิลด์ที่ผู้ใช้กรอก | `200 OK` + Object | `400` ข้อมูลผิดเงื่อนไข / `404` ไม่พบ ID |
| `DELETE` | `/api/books/:id` | ลบรายการหนังสือ | `200 OK` + Object | `400` ID ผิดรูปแบบ / `404` ไม่พบ ID |

**รูปแบบ JSON Response สม่ำเสมอทุก Endpoint**:
* สำเร็จ: `{ "success": true, "message": "...", "data": ... }`
* ผิดพลาด: `{ "success": false, "message": "..." }`

## 🌐 การนำระบบขึ้นใช้งานจริง (Deployment Guide)

### 1. Frontend บน Vercel
* **Root Directory**: `frontend`
* **Framework Preset**: `Vite`
* **Build Command**: `npm run build`
* **Output Directory**: `dist`
* **Environment Variable**: `VITE_API_URL` = `https://[RENDER-BACKEND-URL]`
* **URL Rewrite**: รองรับผ่าน `frontend/vercel.json` ป้องกันหน้า 404 เมื่อรีเฟรช URL หน้าย่อย

### 2. Backend บน Render
* **Service Type**: Web Service
* **Root Directory**: `backend`
* **Runtime**: `Node`
* **Build Command**: `npm ci`
* **Start Command**: `npm start` *(รัน `node index.js` ฟังที่พอร์ต `process.env.PORT` และ `0.0.0.0`)*
* **Environment Variables**:
  * `NODE_ENV` = `production`
  * `DATABASE_URL` = `[Connection String ของ Cloud PostgreSQL เช่น Neon]`
  * `DB_SSL` = `true`
  * `CORS_ORIGIN` = `https://[VERCEL-FRONTEND-URL]`
